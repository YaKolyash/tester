# tester
# Тестер Скорости Сети

Это простая консольная утилита, написанная на Node.js, для измерения средней скорости загрузки с указанного URL-адреса.

## Предварительные требования

Прежде чем запускать скрипт, вам необходимо иметь установленный Node.js и установить библиотеку `axios` для HTTP-запросов.

```bash
npm install axios
```

## Использование

Запустите скрипт из терминала, передав URL для тестирования в качестве аргумента.

```bash
node speed_tester.js <URL>
```

### Пример

Чтобы проверить скорость на большом тестовом файле:

```bash
node speed_tester.js https://example.com/large_file.zip
```

## Как это работает

Скрипт выполняет 10 последовательных GET-запросов к предоставленному URL. Для каждого запроса он измеряет:
1. Время, затраченное на получение полного ответа.
2. Размер загруженных данных.

Затем он рассчитывает и выводит в консоль общий объем данных, среднее время запроса и среднюю скорость загрузки, выраженную в **Мегабитах в секунду (Mbps)**.
